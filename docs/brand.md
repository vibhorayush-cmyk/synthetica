# Synthetica Brand System

## Identity

- Name: **Synthetica**
- Tagline: **Realistic data. Real analytical practice.**
- Voice: professional, concise, technically credible, educational, and welcoming.

## Logo

The original Synthetica mark combines connected data tables, an analytics flow,
and a subtle `S` path. Use the React SVG mark in `frontend/components/brand`.
It is designed for light, dark, and small-size contexts.

Correct: use the complete mark at its natural proportions, with adequate clear
space and indigo on light surfaces. Incorrect: stretch, rotate, recolor with
low-contrast tones, add effects, or replace it with third-party marks.

## Typography and layout

Use the system sans-serif stack with bold, tight tracking for product headings;
use readable normal-weight body copy. Base spacing uses a 4px scale. Standard
cards use a 14px radius and soft, neutral shadows.

## Theme tokens

- Primary indigo: `#4f46e5`
- Dark surface: `#0f172a`
- Light surface: white on `slate-50`
- Focus: visible indigo ring

## Components

Primary buttons are indigo with white text. Secondary buttons use neutral
surfaces. Cards use subtle borders, rounded corners, and restrained shadows.
Avoid overly playful language, excessive gradients, or unsupported claims.
